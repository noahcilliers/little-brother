# Evals, Oct 24–25: Haiku agents on STALE-bench and CooperBench

Headless Claude Code agents (Haiku) in pairs, each on its own branch, graded from git and the benchmark's tests;
no LLM grades anything. Runs whose agent stream shows an API error (rate limits) are voided and left out of
every number. Raw results live in `apps/evals/results/haiku-1025/` (not committed).

Arms, same agents and prompts:

- **off**: no coordination.
- **msg**: a shared mailbox the agents can post to and read (CooperBench's cooperative setting).
- **oracle**: the caller's prompt carries a hand-written note about the teammate's interface change (STALE-bench's
  "informed" condition). An upper bound on being told in advance.
- **on**: Little Brother.

Metrics: **interference** = a test that passes on its own branch fails after a clean merge (STALE-bench's
Δblind); **merged success** = the merged tree passes every check; **both solved alone** = each agent's own task
passes on its own branch; **detection** = the planted clash was flagged (hit), flagged as the wrong kind
(mislabel) or not flagged (miss).

## CooperBench: two features on one real repo

Five tasks (click, jinja, dirty-equals). Rate limits voided most of the first passes.

| Arm | Runs | Merge conflicts | Merged success | Both solved alone | $/run | New tokens/run | Detection hit/mislabel/miss |
|---|---|---|---|---|---|---|---|
| off | 16 | 44% | 25% | 62% | $0.024 | 46.9k | – |
| msg | 5 | 20% | 40% | 60% | $0.023 | 48.3k | – |
| on | 14 | 29% | 0% | 14% | $0.027 | 52.6k | 7 / 4 / 2 |

Fewer merge conflicts, but the agent that was behind often gave up after a same-file denial. That's what the
line-level claim fix (agents may edit elsewhere in the file) is for; it landed after most of these runs.

## What the runs found and we fixed

1. Deny-once denied every retry: the hook got the open catch row back and denied on its stored action.
2. Calls inside Python f-strings were invisible, so a signature change was never matched to its caller.
3. Two new functions in one existing file were reported as a duplicate file.
4. A catch raised from an earlier, milder notice counted as a repeat and was let through.
5. Notices found after an agent's edit were only delivered as warnings and never reached it.
6. Under load, a cold Node start plus a slow backend crossed Claude Code's 3 s hook timeout and the deny was dropped.
7. Agents read a bare denial as "stop the task"; every denial now says how to finish.
8. A claim won by being further along blocked the whole file; it now holds the claimed lines.
9. Interface denials told the caller to wait for the dashboard, and it stopped.
10. The contract card listed a renamed-away name as an export and showed removed lines.

## Not yet fixed

- The caller can be denied twice on the same interface clash in some runs.
- STALE-bench interference with Little Brother on is barely below the no-coordination arm once both agents
  finish their tasks.
